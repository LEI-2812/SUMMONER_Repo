## QA-DONE-003

### 원본 ID

`QA-001`

### 제목

Fight 1Stage 진입 중 `Summon.Update()` NullReferenceException 재검증

### 문제

Fight 1Stage 진입 중 `Summon.Update()`가 NullReferenceException을 낼 수 있었다.

### 원인

일부 파생 소환수의 `Awake()`가 부모 `Summon`의 공통 초기화를 호출하지 않아 View 참조 초기화가 누락될 수 있었다.

### 수정 내용

DevAgent가 `Summon.Awake()`를 `protected virtual`로 바꾸고, 자체 `Awake()`가 있는 파생 소환수가 `base.Awake()`를 호출하도록 수정했다.

### 관련 파일

- `Assets/Script/Summons/Summon.cs`
- `Assets/Script/Summons/*.cs`
- `Assets/Script/Battle/View/SummonStatusView.cs`
- `Assets/Script/Battle/View/SummonImageView.cs`
- `Assets/Script/Battle/View/SummonSoundView.cs`

### 최종 확인

- 2026-06-02: Fight 1Stage가 플레이어 턴까지 진입했고 Console error는 0개였다.
- 2026-06-02: `Summon.Update()` NullReferenceException은 재현되지 않았다.
- 2026-06-02: MCP EditMode `Summoner.EditModeTests.SummonDataRegressionTests` 4/4 통과
- 2026-06-02: 활성 씬 `Fight Screen_1Stage`, Console error/warning 0개 재확인

### 메모

소환수 이미지, 색상, 효과음과 실제 소환/공격 동작 확인은 `QA-010`에 남긴다.
승리 Alert, Retry, 진행 저장 확인은 `QA-002`에 남긴다.

## QA-DONE-004

### 원본 ID

`QA-011`

### 제목

Fight 1Stage 진입 중 `DontDestroyOnLoad` warning 재검증

### 문제

Fight 1Stage Play 진입 중 `DontDestroyOnLoad only works for root GameObjects or components on root GameObjects.` warning이 발생했다.

### 원인

`GameSaveController`가 Fight 1Stage에서 `__Systems` 하위 오브젝트인데 `GameSaveController.Awake()`에서 `DontDestroyOnLoad(gameObject)`를 호출했다.

### 수정 내용

DevAgent가 `GameSaveController`가 `DontDestroyOnLoad` 호출 전에 root GameObject가 되도록 부모를 해제했다.

### 관련 파일

- `Assets/Script/Save/GameSaveController.cs`

### 최종 확인

- 2026-06-02: MCP EditMode `GameSaveController_MovesToRootBeforeDontDestroyOnLoad` 1/1 통과
- 2026-06-02: Fight 1Stage Play 진입 후 Console warning 0개
- 2026-06-02: Fight 1Stage Play 진입 후 Console error 0개
- 2026-06-02: 런타임 `GameSaveController`는 단독 오브젝트로 조회되고 `__Systems/GameSaveController` 경로는 존재하지 않음

### 메모

MCP `execute_menu_item("Edit/Play")`는 timeout으로 반환됐지만, 직후 활성 씬과 HUD 로드, Console 로그, 런타임 오브젝트 조회가 가능해 Play 진입 후 상태를 확인했다.
