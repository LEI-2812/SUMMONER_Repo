## 3. 상세 QA 기록

### BT-001. 소환수 뽑기 - 후보 3개 표시

- 우선순위: 높음
- 확인 내용: 소환 버튼 클릭 시 후보 소환수 3개가 표시되는지 확인
- 기대 결과: 후보 3개가 PickSummonPanel에 표시된다
- 현재 결과: 아직 QA 전
- 상태: Pending
- 다음 조치: 소환 버튼 후 후보 확인
- 관련 파일: SummonController.cs

---

### BT-002. 소환수 뽑기 - 후보 중복 방지

- 우선순위: 중간
- 확인 내용: 표시된 후보 3개가 중복되지 않는지 확인
- 기대 결과: 한 번의 선택 후보 안에서 같은 소환수가 반복되지 않는다
- 현재 결과: 아직 QA 전
- 상태: Pending
- 다음 조치: 3개 후보 중복 여부 확인
- 관련 파일: SummonController.cs

---

### BT-003. 소환수 뽑기 - 등급 확률

- 우선순위: 중간

- 기대 결과: 반복 실행 시 등급 분포가 기준 확률과 크게 어긋나지 않는다
- 현재 결과: 아직 QA 전
- 상태: Pending
- 다음 조치: 1000회 시뮬레이션 후보 작성
