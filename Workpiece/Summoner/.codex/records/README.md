# Records

이 폴더는 과거 작업을 빠르게 찾기 위한 요약 인덱스다.
새 작업의 긴 기록을 여기에 쓰지 않는다.

## 파일 역할

- `history-summary.csv`: 날짜별 과거 작업 요약 표

## 운영 기준

- 새 작업 완료는 `.codex/dev-log/YYYY-MM-DD.md`에 1~3줄로 먼저 남긴다.
- 오래 쌓인 dev-log를 정리할 때만 `history-summary.csv`에 압축 반영한다.
- QA 상세 증거는 `.codex/archive/qa/`에 둔다.
- 오래된 원본 기록은 `.codex/archive/`에 둔다.
- legacy CSV 원본은 `.codex/archive/legacy-csv/`에만 둔다.
