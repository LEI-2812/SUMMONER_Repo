## DEV-030 Cat 예측 damage 기준 정합성 검토

- `CatAttackPrediction.GetIndexOfNormalAttackCanKill`은 `cat.GetAttackPower()`로 일반공격 처치 가능성을 판단한다.
- 실제 Cat 일반공격은 `ClosestEnemyAttackEffectInstanceCreate`에서 `attacker.GetAttackPower()`로 피해를 적용하므로 기준이 일치한다.
- `CatAttackPrediction.GetIndexOfSpecialCanKill`은 `cat.GetHeavyAttackPower()`로 특수공격 처치 가능성을 판단한다.
- 실제 Cat 특수공격은 `Cat.CatSpecialAttackWithHeavyAttackPowerExecute`에서 `SetAttackPower(GetHeavyAttackPower())` 후 동일 근접공격 effect를 타므로 기준이 일치한다.
- `GetMostDamageAttack`의 `specialAttack.GetSpecialDamage()`도 Cat 특수공격 전략 생성 시 `GetHeavyAttackPower()` 값이 들어가므로 현재 기준과 일치한다.
- 코드 변경 없이 완료하고 FlowAgent로 돌린다.
