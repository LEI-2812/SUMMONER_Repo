# 2026-06-02 작업 기록

## 1. 작업 요약

오늘은 소환수 데이터화, 옵션 시스템 버그 수정, Story 입력 처리 수정, QA 문서 구조 정리를 진행했다.

- 플레이어 소환수 6종을 `SummonData` 에셋 기반 초기화로 연결했다.
- 오디오 볼륨 0 처리와 비디오 저장 인덱스 복구 방어를 추가했다.
- Story Only Mouse 옵션이 Space 입력에 반영되도록 수정했다.
- 에이전트 실행 문서를 `.codex` 중심으로 정리했다.
- QA-006은 사용자 수동 확인으로 볼륨 0 음소거와 복구가 정상 동작함을 확인했다.

역할:
- DevAgent, QAAgent, FlowAgent 작업이 같은 날짜에 이어졌다.

---

## 2. 작업 배경

이 작업을 진행한 이유는 다음과 같다.

- 기존 문제:
  - 소환수 능력치와 공격 값이 코드에 흩어져 있었다.
  - 옵션 UI에서 볼륨 0, 잘못된 비디오 저장 인덱스, Story 입력 옵션 처리에 방어가 부족했다.
  - QA 실행 문서가 여러 위치에 흩어져 다음 작업 기준이 흐려졌다.
- 작업 목적:
  - 기존 기능을 유지하면서 데이터화와 옵션 안정성을 점진적으로 개선한다.
  - QA 문서의 현재 상태와 다음 작업 기준을 명확히 한다.
- 관련 기능:
  - BattleContent, OptionSystem, StorySystem, QAInfrastructure

## 3. 작업 내용

### 3.1 소환수 데이터화

#### 변경 전

플레이어 소환수 값이 각 C# 클래스에 직접 들어 있었다.

#### 변경 후

- `SummonData`와 `SummonAttackData` 구조를 추가했다.
- Cat, Rabbit, Snake, Wolf, Eagle, Fox 6종 프리팹이 각 `SummonData` 에셋을 참조하게 했다.
- 기존 코드 fallback은 아직 유지했다.

#### 관련 파일

- `Assets/Script/Summons`
- `Assets/Script/Summons/Data`
- `Assets/Prefabs/SummonPrefab`
- `Assets/Tests/EditMode/Editor/SummonDataRegressionTests.cs`

### 3.2 옵션 시스템 안정화

#### 변경 전

- 오디오 볼륨 0에서 `Mathf.Log10(0)` 위험이 있었다.
- 잘못된 비디오 저장 인덱스가 있으면 모든 토글이 꺼질 수 있었다.

#### 변경 후

- 볼륨 0 이하는 `-80f` 음소거 dB 값으로 처리한다.
- 잘못된 비디오 저장 인덱스는 기본값 0으로 복구한다.

#### 관련 파일

- `Assets/Script/Option/AudioSettingView.cs`
- `Assets/Script/Option/VideoSettingView.cs`
- `Assets/Tests/EditMode/Editor/GameSystemStaticRegressionTests.cs`

### 3.3 Story 입력 옵션 반영

#### 변경 전

Only Mouse 옵션이 켜져도 Story 공통 Space 입력이 대사를 진행할 수 있었다.

#### 변경 후

Story 공통 입력 처리에서 Only Mouse 옵션을 확인하도록 수정했다.

#### 관련 파일

- `Assets/Script/Story/Scenario/StoryScenarioControllerBase.cs`
- `Assets/Tests/EditMode/Editor/StorySystemStaticRegressionTests.cs`

### 3.4 QA 문서 구조 정리

#### 변경 전

실행 문서와 QA 상태 문서가 여러 위치에 흩어져 있었다.

#### 변경 후

- 실행 문서를 `.codex` 중심으로 정리했다.
- 현재 QA 원본은 `.codex/qa/active-qa.md`로 둔다.
- 열린 이슈 요약은 `.codex/workflow/issue-board.md`가 담당한다.
- `current-task.md`는 새 작업 시작 시 이전 작업을 유지하지 않고 덮어쓴다.
- `Auto QA Mode`는 기존 기능 복구 최소 수정과 검증을 자동 진행한다.
- `Auto Dev Mode` 요청은 준비 전까지 `Default Mode`로 전환한다.

#### 관련 파일

- `.codex/workflow`
- `.codex/qa`
- `.codex/agents`

## 5. 발생한 문제와 해결

### 문제

MCP PlayMode, Console 조회, 일부 씬 조회가 반복적으로 timeout 또는 connection error를 냈다.

### 원인

현재 결과만으로는 게임 코드 실패가 아니라 MCP/Unity Editor 실행 안정성 문제로 분류한다.

### 해결

기능 실패와 QAInfrastructure 문제를 분리했다.
MCP timeout 상세 로그는 `.codex/qa/active-qa.md`의 QA-003에 남기고, WorkLog에는 요약만 남긴다.
