- QAReviewAgent를 DevAgent 뒤에 매번 실행하지 않고, 기능 목표 완료 후 실행하는 흐름으로 정리했다.

- DevAgent가 개발 중 유지보수성 검토를 계속 담당하도록 했다.
- QAReviewAgent는 기능 목표 완료 후 컴파일, 테스트, QA, 최종 유지보수 리스크 검토를 담당하도록 역할을 좁혔다.
- 작업 결과 보고에는 다음 작업, 승인 필요 여부, 검증 대기 여부를 포함하도록 정리했다.
- FlowAgent Close 단계에서 날짜별 작업 기록을 갱신하는 기준을 추가했다.
- `current-task.md`가 기능 구현 상태를 관리하는 기준 문서임을 명확히 했다.
- 기능 구현 상태 섹션에 상태, 기능 목표, 기능 완료 조건, 현재 완료한 개발, 남은 개발, QA 호출 조건을 기록하도록 정리했다.
- 기능 개발이 거의 끝났는데도 DevAgent가 계속 개발만 이어가는 문제를 줄이기 위해 `QA필요` 상태를 추가했다.
- DevAgent가 작업 결과마다 기능 완료 조건을 확인하고, 남은 개발이 없거나 불명확하면 QAReviewAgent로 전환하도록 정리했다.
- `current-task.md`의 기능 구현 상태에 `QA 전환 판단` 항목을 추가했다.
- QA 로직 설계 책임을 QAReviewAgent에 명확히 부여했다.
- FlowAgent는 QA 기준 범위를 정리하고, DevAgent는 개발 중 발견한 위험 지점을 다음 QA 확인 항목으로 남기도록 정리했다.
- 자동 개발 모드에서는 기존 테스트로 부족할 때 QAReviewAgent가 최소 테스트 코드를 직접 생성할 수 있도록 정리했다.
- 턴 진행 기능 QA는 전투 시작 후 플레이어 턴과 적 턴을 최소 2~3회 왕복 확인하도록 기준을 강화했다.
- 남아 있던 `완료전QA` 표기를 `QA필요`로 맞췄다.
- QAReviewAgent는 테스트 코드 수정/생성은 허용하되 제품 코드는 직접 수정하지 않도록 정리했다.
- `current-task.md`의 긴 완료 이력을 줄이고 현재 판단에 필요한 최근 QA와 완료 요약만 남기도록 정리했다.

- 기능 목표가 완료되기 전에는 QAReviewAgent로 넘기지 않는다.
- 사용자가 `검증해`, `QA해`, `테스트해`라고 요청하면 기능 완료 전이라도 검증을 실행할 수 있다.
- 기능 개발 완료, QA 완료, 구조 결정, 작업 정책 변경은 날짜별 작업 기록에 남긴다.
- 단순 질문 답변, 단순 파일 확인, 작은 문구 수정, 기능 개발 중간 단계는 dev-log에 남기지 않는다.
- 기능 구현 상태는 `.codex/workflow/current-task.md`에서 관리한다.
- 새 기능 작업을 시작할 때 FlowAgent가 기능 목표, 기능 완료 조건, QA 호출 조건을 먼저 작성한다.
- DevAgent가 QA로 넘기지 않으려면 `남은 개발` 항목을 구체적으로 기록해야 한다.
- 기능 완료 조건을 만족했거나 남은 개발이 불명확하면 `QA필요`로 전환한다.
- 기능 구현이 끝난 상태는 `QA필요`로 표시하고 QAReviewAgent 검증 대기로 둔다.
- `current-task.md`의 기능 상태값은 `시작전`, `진행중`, `검증대기`, `QA필요`, `QA진행중`, `QA완료`, `구현완료`, `보류`, `후속작업대기`로 통일했다.
- QA 기준의 큰 범위는 FlowAgent가 정하고, 실제 QA 로직은 QAReviewAgent가 기능 완료 조건을 기준으로 설계한다.
- 현재 작업판에는 긴 완료 이력을 누적하지 않고, 상세 기록은 dev-log와 archive를 기준으로 확인한다.
- 자동 생성 테스트는 기능 완료 조건을 확인하는 가장 작은 범위로 제한한다.
- 가장 작은 범위라도 기능 흐름을 실제로 증명할 수 있는 깊이를 포함해야 한다.
- 턴 진행 기능은 한 번의 턴 전환만으로 Pass 처리하지 않는다.
- 테스트 생성을 위해 씬, 에셋, 저장 데이터 구조, 외부 서비스 연결 변경이 필요하면 자동 생성하지 않는다.

- 갱신할 내용이 없으면 workflow에 불필요한 이력을 누적하지 않고 결과 보고에 `변경 없음`과 이유를 남긴다.
- 정책 변경 기록은 날짜별 dev-log에 짧게 남긴다.
