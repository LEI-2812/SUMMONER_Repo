# Archive

이 폴더는 완료된 작업 기록과 과거 문서를 보관한다.

현재 작업 판단에 매번 필요하지는 않지만, 과거 결정의 근거가 되는 문서를 둔다.

## 보관 기준

- `qa/`: 완료된 QA 상세

`change-summary.md`, `session-guide.md`, `workflow-history-YYYY-MM.md`, 별도 `code-review` 문서는 더 이상 새로 만들지 않는다.
완료 요약은 `.codex/dev-log/YYYY-MM-DD.md`에 짧게 남긴다.

## 운영 기준

- 현재 작업판 역할을 하는 문서는 `.codex/workflow/`에 둔다.
- 완료된 작업 기록은 이 폴더로 옮긴다.
- 다시 확인할 가능성이 있는 QA 상세는 `qa/` 아래에 둔다.
- 현재 세션 시작 때 이 폴더를 기본으로 읽지 않는다.
