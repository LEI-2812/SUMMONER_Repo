# Smoke Regression Checklist

기능 목표가 완료됐거나 자동 개발이 끝난 뒤에는 아래 항목만 빠르게 확인한다.
목표는 완전한 QA가 아니라, 개발 결과가 기본적으로 돌아가는지 확인하는 것이다.

## 기본 확인

- [ ] 컴파일이 통과한다.
- [ ] 변경된 기능과 직접 관련된 EditMode 테스트가 통과한다.
- [ ] 가능하면 관련 PlayMode 또는 수동 실행을 1회 확인한다.
- [ ] 변경된 화면이나 버튼이 정상적으로 열린다.
- [ ] 핵심 입력 흐름이 동작한다.
- [ ] 저장/불러오기와 직접 관련된 변경이면 저장값이 깨지지 않는다.
- [ ] Console에 명확한 게임 코드 오류가 없다.

## 기능별 확인 깊이

- [ ] 턴 진행 기능은 전투 시작 후 플레이어 턴과 적 턴을 최소 2~3회 왕복 확인한다.
- [ ] 턴 진행 기능은 한 번의 플레이어 턴 시작이나 적 턴 진입만으로 Pass 처리하지 않는다.
- [ ] 전투 결과 기능은 승리 조건과 패배 조건 중 변경과 직접 관련된 조건을 확인한다.
- [ ] 버튼/입력 기능은 정상 입력과 차단되어야 하는 입력을 함께 확인한다.
- [ ] 씬 연결 기능은 씬 로드 직후 필요한 런타임 컨트롤러와 참조가 존재하는지 확인한다.

## 환경 오류 처리

- [ ] MCP timeout, 501, WebSocket error는 게임 코드 실패와 분리한다.
- [ ] Unity가 메인 프로세스가 아니어서 발생한 Test Time exceeded는 코드 실패와 분리한다.
- [ ] 같은 MCP 오류는 2회까지만 재시도한다.
- [ ] PlayMode 확인이 막히면 `Blocked`로 기록하고 다음 개발 작업으로 넘어간다.

## 결과 기준

- `Pass`: 핵심 흐름이 실제로 확인됨
- `검증부족`: 사전에 정한 QA 깊이 기준 중 확인하지 못한 항목이 남음
- `Needs Fix`: 게임 코드 또는 연결 문제로 기대 동작이 깨짐
- `Blocked`: 도구나 환경 문제 때문에 확인 불가
