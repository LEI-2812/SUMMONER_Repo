# 전체 확인 목록

큰 기능 수정 후 기존 기능이 깨지지 않았는지 확인한다.

## 1. 전투 흐름

- [ ] 전투 씬이 정상 실행된다.
- [ ] 플레이어 턴이 정상 시작된다.
- [ ] 플레이어 턴 종료 후 적 턴으로 넘어간다.
- [ ] 적 턴 종료 후 플레이어 턴으로 돌아온다.
- [ ] 적 전멸 시 승리 Alert가 표시된다.
- [ ] Clear Turn 초과 시 패배 Alert가 표시된다.

---

## 2. 소환 시스템

- [ ] 소환 후보가 3개 표시된다.
- [ ] 소환수를 선택할 수 있다.
- [ ] 빈 Plate에 소환수를 배치할 수 있다.
- [ ] 이미 소환수가 있는 Plate 처리 정책이 의도대로 동작한다.
- [ ] Redraw 버튼이 정상 동작한다.

---

## 3. Plate 시스템

- [ ] Plate에 마우스를 올리면 상태 패널이 표시된다.
- [ ] Plate에서 마우스를 빼면 상태 패널이 사라진다.
- [ ] 소환수가 없는 Plate에서 에러가 발생하지 않는다.
- [ ] 공격 대상 하이라이트가 정상 표시된다.
- [ ] 적 사망 후 Plate 정렬이 정상 동작한다.

---

## 4. Story 시스템

- [ ] 첫 대사가 정상 표시된다.
- [ ] 클릭으로 대사가 진행된다.
- [ ] Space 입력 정책이 옵션과 일치한다.
- [ ] Story Skip 버튼이 옵션과 일치한다.
- [ ] 스토리 종료 후 올바른 씬으로 이동한다.

---

## 5. UI / Option

- [ ] 버튼 클릭이 정상 동작한다.
- [ ] 설정창 탭 전환이 정상 동작한다.
- [ ] 오디오 볼륨 0에서 에러가 없다.
- [ ] 비디오 설정 저장값이 잘못됐을 때 기본값으로 복구된다.
- [ ] 턴 상태 UI가 현재 턴과 일치한다.

---

## 6. 저장 / 불러오기

- [ ] 새 게임 시작이 정상 동작한다.
- [ ] 이어하기가 저장된 스테이지로 이동한다.
- [ ] 스테이지 선택 저장이 정상 동작한다.
- [ ] 전투 클리어 후 진행도가 저장된다.
- [ ] 저장 데이터 초기화가 정상 동작한다.

---

## 7. 공통 확인

- [ ] Console error가 없다.
- [ ] NullReferenceException이 발생하지 않는다.
- [ ] warning 로그가 있으면 원인을 분류했다.
- [ ] 기존 기능이 의도치 않게 변경되지 않았다.
- [ ] PlayMode timeout은 코드 Fail과 구분해 기록했다.
