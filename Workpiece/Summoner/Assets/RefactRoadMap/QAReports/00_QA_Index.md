# QA Index

QA 문서는 기능별로 나누고, 각 문서는 같은 구조로 기록한다.
기존 CSV 파일은 이전 기록 보관용으로 유지하고, 앞으로 사람이 읽고 기록하는 문서는 Markdown을 기준으로 사용한다.

## 1. 문서 목록

| 문서 | 범위 | 사용 목적 |
|---|---|---|
| 01_GameSystem_QA.md | 시작 화면, 저장, 이어하기, 스테이지 이동 | 게임 시작과 진행 저장 확인 |
| 02_StorySystem_QA.md | CSV 대사, 대사 진행, 스토리 연출, 씬 이동 | 스토리 흐름 확인 |
| 03_BattleCore_QA.md | 턴, 마나, 공격, 상태이상, 승패 판정 | 전투 핵심 규칙 확인 |
| 04_BattleContent_QA.md | 소환수 뽑기, 배치, 공격 전략, 적 AI | 전투 콘텐츠 동작 확인 |
| 05_OptionSystem_QA.md | 오디오, 비디오, 게임플레이 옵션, 설정 저장 | 설정값 적용과 재시작 후 유지 확인 |

## 2. 상태 기준

| 상태 | 의미 |
|---|---|
| Pending | 아직 확인 전 |
| Pass | 확인 완료, 문제 없음 |
| Fail | 문제 발생 |
| Blocked | 환경 문제로 확인 불가 |
| Fixed | 수정 완료, 재확인 필요 |
| Closed | 재확인까지 완료 |

## 3. 기록 방법

```text
1. 기능별 QA 문서를 연다.
2. "QA 체크 항목"에서 확인할 항목을 고른다.
3. 실제 확인 내용은 "상세 QA 기록"에 적는다.
4. 문제가 있으면 같은 문서의 "발견한 버그"에 추가한다.
5. 테스트가 끝나면 "QA 히스토리"에 날짜별 기록을 남긴다.
```
