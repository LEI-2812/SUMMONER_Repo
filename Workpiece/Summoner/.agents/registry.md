# Agent Registry

사용 가능한 에이전트 목록과 호출 조건을 관리한다.

## 핵심 에이전트

| ID | 한글 이름 | 주요 책임 | 사용 조건 |
|---|---|---|---|
| CoordinatorAgent | 작업 조율 에이전트 | 기능 슬라이스 선정, 호출 대상 결정, active 상태 관리 | 모든 작업 시작/종료, 범위 재정리 |
| DevAgent | 개발 에이전트 | 코드 구현, 기능 슬라이스 안의 작은 보정, 1차 확인 | 기본 개발 흐름 |
| VerificationAgent | 검증 에이전트 | review mode와 QA mode로 설계/동작 검증 | 위험 변경, 기능 게이트, 검증 요청 |

## 선택 확장 에이전트

| ID | 한글 이름 | 주요 책임 | 사용 조건 |
|---|---|---|---|
| DocumentationAgent | 문서 정리 에이전트 | WorkLog, handoff, release note, 큰 결정 기록 | 기능 완료, handoff, 릴리즈 문서 필요 |
| ReleaseAgent | 릴리즈 에이전트 | 릴리즈 범위, 검증 상태, 배포 위험 정리 | 릴리즈/배포/버전 정리 요청 |

## 확장 규칙

- 새 에이전트는 기존 역할과 책임이 겹치지 않을 때만 추가한다.
- 상시 서브에이전트를 만들지 않는다.
- 문서 작성 전문 에이전트는 기능 완료/handoff/release 때만 호출한다.
- 특정 도메인 Specialist가 필요하면 먼저 registry에 등록하고 role 문서를 만든 뒤 사용한다.
- 작업 유형별 팀 문서나 템플릿 문서는 만들지 않는다.
